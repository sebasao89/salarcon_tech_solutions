# Reglas

- La entrada es una lista de diccionarios de retos válidos.
- Cada reto es un diccionario con "título" como texto y "completado" como booleano.
- El porcentaje es el número de completados dividido entre el total, por 100.
- El resultado se redondea con round de Python: al entero más cercano; en un empate exacto, al entero par.
- Si no hay retos, el progreso es 0.
- La función no debe modificar la lista ni sus diccionarios.
- Validar entradas de otros tipos queda fuera del alcance de este ejercicio.
